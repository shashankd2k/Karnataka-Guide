## 2. Zero Runtime Hotlinking Guarantee
- 100% of monument assets are bundled locally in `public/monuments/`.
- No runtime network requests or image hotlinking are performed.
- If vector rendering is unavailable, the UI gracefully renders CSS heritage gradient cards.
